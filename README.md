# Reel影片製作

明亮、多彩、繁體中文／英文切換的互動學習網。已隨附 **77 支有中文旁白、燒錄字幕的 MP4 範例**，不需要 API Key、登入或外部字體服務。

## 開始使用

- 快速瀏覽：直接開啟 `index.html`，可以觀看本機影片、搜尋課程與使用提示詞工具。
- 完整 PWA：電腦已安裝 Node.js 時，雙擊 `啟動學習網.cmd`，或在本資料夾執行 `node server.mjs`，瀏覽 `http://localhost:4177`。使用期間保留啟動視窗。
- 網路發布：將下列網站檔案完整放到 GitHub 儲存庫根目錄；以 GitHub Pages 發布後使用 HTTPS 網址。

直接使用 `file://` 瀏覽時，安裝、Service Worker 與離線影片管理無法啟用；瀏覽器也可能限制剪貼簿或本機設定儲存。網站會提示限制。這是安全來源要求，參考 [MDN Service Worker API](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API)。

## 教材與互動

| 分類 | 數量 | 範例長度 |
| --- | ---: | --- |
| 影片風格 | 15 | 約 20 秒 |
| 文字表現手法 | 20 | 約 20 秒 |
| 動畫風格：視覺風格 | 22 | 約 10 秒 |
| 動畫風格：場景手法 | 20 | 約 10 秒 |

支援中英文關鍵字搜尋、分類篩選、收藏、手動標記完成、繼續學習、兩支影片並排比較、每課特徵選擇題、每課實作提示詞、可編輯的提示詞組合器、複製／TXT 下載、八種實作挑戰及交片檢查表。

完成紀錄由學習者自行標記，不把打開影片當作已完成。收藏、進度、檢查表與設定只存在目前瀏覽器的 localStorage，清除網站資料會移除紀錄。影片下載按鈕以中文主題命名；網站內的媒體使用穩定的英數代號。

英文模式翻譯介面、課程名稱、解說、特徵、題目與提示詞。**原有範例影片仍使用中文旁白與燒錄中文字幕**，不會因切換介面而改變。工作室內自己輸入的主題與訊息保留原文；切換語言會重新產生提示詞，請先複製要保留的自行修改內容。

## 七項顯示與操作設定

1. 全螢幕：開啟／關閉；以瀏覽器實際狀態顯示，部分手機瀏覽器不支援。
2. 操作音效：開啟／關閉；使用 Web Audio 即時合成輕量提示音，只有使用者互動後才發聲。此設定不控制影片自己的音量。
3. 裝置呈現：自動／手機／平板／電腦；調整內容寬度，仍受實際螢幕寬度限制。
4. 版面：自動／直式／橫式；調整卡片排列，不鎖定裝置方向。
5. 語言：繁體中文／English。
6. 字體：縮小 18px／標準 20px／放大 23px 內文基準，標題與輔助字級有各自的階層。
7. 色系：跟隨系統／亮色／暗色。

支援 RWD、鍵盤操作、焦點提示、原生對話框、略過導覽與減少動態偏好。雙片比較會在播放其中一支時暫停另一支。

## 離線與安裝

首次以 HTTPS／localhost 開啟後，Service Worker 會準備介面、教材、77 張封面、本地字體與圖示。影片不自動全部下載，可在課程內逐支儲存，或使用「離線影片管理」儲存全部，影片合計約 **103 MiB**。首次安裝仍需等網站資產下載完成；完成後重新開啟頁面即可由 Service Worker 接管。

離線影片以 Cache Storage 儲存，支援 MP4 Range 請求，能在已儲存影片中拖曳進度。中途取消會保留已成功儲存的影片。「清除離線影片」不清除收藏與進度。下載失敗會提示，瀏覽器可能因容量或政策清除快取，請保留本機原檔。參考 [MDN PWA 快取指南](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Caching)。

支援安裝提示的瀏覽器會顯示「安裝學習網」。其他瀏覽器可從選單使用「安裝」或「加入主畫面」，實際名稱與支援度依裝置而異。

## GitHub Pages 上傳

1. 建立 GitHub 儲存庫，把本資料夾的網站檔案放在儲存庫根目錄，確認首頁就是 `index.html`。
2. 前往 Settings → Pages，選擇 Deploy from a branch，選擇 `main` 與 `/ (root)`，儲存。
3. 等待 GitHub 完成發布，開啟 Pages 提供的 HTTPS 網址。保留 `.nojekyll`。

所有路徑都使用相對位置，可放在 `https://帳號.github.io/儲存庫名稱/` 的子路徑，無需改寫網址。此交付包已備妥本機檔案，尚未代為建立儲存庫或發布。Pages 設定依據 [GitHub 官方建立網站說明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

影片與字體容量較多，建議以 Git 或 GitHub Desktop 一次提交完整資料夾，避免瀏覽器批次上傳遺漏。所有單一影片都小於 100 MB。

## 修改與維護

- 新增或修改教材：編輯 `data/catalog.js`，同步放入影片與 WebP 封面。頁面上的固定分類數量、進度總數與練習配對也應同步調整。
- 修改介面：編輯 `index.html`、`styles.css`、`app.js`；字串在 `i18n.js`。
- 更新發布版：同步更新 `precache.js`，將 `sw.js` 中的 `reel-shell-v1` 版本號提高；新版本在舊頁面全部關閉後啟用。影片若替換同一路徑，請先清除離線影片再儲存，或提高媒體快取版本並同步修改 `app.js`。
- 網站不呼叫 Azure 或其他生成 API，不含任何 API Key。提示詞是供學習者複製到自己的工具使用，網站本身不生成新影片。
